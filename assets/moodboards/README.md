# Moodboards — Brand References

Five external references provided by Bill (Apr 20, 2026) that informed the locked brand direction. This file is the **link + one-line summary index**; full per-reference analysis (palette, type, layout, signature devices, pulls, anti-moves) lives in [docs/brand-research-notes.md](../../docs/brand-research-notes.md).

Image captures of each reference should be added to this folder as `reference-{n}-{slug}.png` for offline reference — useful if a case-study URL changes or goes dead.

---

## The five references

### 1. Paris Electronic Week 2022 — Diplomatie Studios
[the-brandidentity.com](https://the-brandidentity.com/project/diplomatie-studios-identity-for-paris-electronic-week-2022-is-a-kaleidoscopic-collision-of-colour)

Kaleidoscopic CMYK collisions (electric magenta, acid yellow, cyan) pinned by rigid typographic frames. **Pull:** the "light bleed pinned under a hard type lockup" move. **Avoid:** multi-hue rainbow — would dilute the indigo anchor.

### 2. SPRING Performing Arts Festival — LAVA
[lava.nl](https://lava.nl/progress/spring-performing-arts-festivals-new-identity/)

Soft photographic gradient blobs ("spring bloom") used as a recurring container, paired with crisp editorial typography. **Pull:** the soft color-field shape as a recurring container (signature device #4 in the brand system). **Avoid:** pastel warmth and book-like whitespace.

### 3. Adam Ho — Personal site + Archetype interview
[adamho.com](https://www.adamho.com/) · [archetype.fund interview](https://www.archetype.fund/media/in-conversation-with-adam-ho)

Bill's reference for a disciplined solo-founder personal-brand voice. Relevant as a model for the Layered Logic parent-brand posture while the venture is still solo.

### 4. Intrinsic — Pentagram identity + Felix Faire generative system
[pentagram.com](https://www.pentagram.com/work/intrinsic) · [felixfaire.com](https://felixfaire.com/work/intrinsic)

**The primary "gradients + hard outlines" reference.** Volumetric soft gradients (fog, light fields) sitting *behind* razor-thin wireframe geometry — two layers that never blend. **Pull:** the visual logic of wireframe-over-bloom (signature device #3). **Avoid:** the heavy 3D rendering workload — adopt the grammar, don't out-render a CG studio.

### 5. IBM Quantum — Field.io brand visuals
[field.io](https://field.io/work/ibm-quantum-brand-visuals)

Scientific-instrument framing — flowing ribbon gradients "annotated" with mono labels and tick marks at the edges. The "annotated sublime." **Pull:** the annotation layer — mono labels, tick marks, thin rules (signature device #2, the mono tick-mark frame). **Avoid:** IBM blue — the anchor here is indigo (cooler, more saturated).

## Shared grammar extracted from these five

From [brand-research-notes.md §Synthesis](../../docs/brand-research-notes.md):

> Soft volumetric color (gradient, fog, bloom, light field) treated as the *subject*, pinned and measured by a hard, precise typographic/geometric overlay. The soft thing is ambient and emotional; the hard thing is technical and first-person. **Tension between the two is the brand.**

The five references converge on: dark-mode ground, one saturated anchor color (for this brand, Indigo Reference `#4A25FF`), disciplined grotesque + mono type pairing, and hard 1px rules framing soft gradient bloom.
